Steps to Find the hardware failure or troubleshooting problem

Battery health

How to Check Battery Health on Windows

  1. Open Command Prompt: Press Windows + R, type cmd, and press Enter (or search for cmd in the Start menu, right-click, and select Run as administrator).
  2. Run the Report Command: Type powercfg /batteryreport and press Enter.
  3. Open the Report: The command will save an HTML file (usually to C:\Users\[Your_Username]\battery-report.html). Copy the path shown in the prompt, paste it into your File Explorer address bar, and open it in any web browser.
  4. Compare Capacities: Look under the Installed battery section for:
    • Design Capacity: The amount of charge the battery was built to hold.
    • Full Charge Capacity: The amount of charge the battery can actually hold now.

Formula: (Full Charge Capacity / Design Capacity) * 100. A health percentage dropping below 80% (or under 60–70% depending on the brand) typically means it is time for a replacement

Display failure

How find the display issue

The Symptom:
Blank screen, vertical/horizontal lines, flickering, or discolored patches.
How to Check:
External Monitor Test:
  • Connect your computer to an external monitor or TV via HDMI/USB-C.
  • If the external screen looks normal, your laptop's screen panel, display ribbon cable (LVDS/eDP), or integrated GPU output is at fault.
  • If the external monitor also shows lines or no signal, it points toward the main graphics processor (GPU) or motherboard.
Lid Movement Test:
Gently tilt or move the laptop lid back and forth. If the screen flickers or changes color as you move it, it’s a loose or damaged physical display cable

Keyboard Failure

The Symptom:
Certain keys stop working, type random characters, or the entire keyboard freezes.
How to Check:
Software Check:
Boot into Safe Mode or use an On-Screen Keyboard (Windows Search -> On-Screen Keyboard) to see if clicks register. Reinstall or update the keyboard driver in Device Manager, or run a malware scan (as some viruses cause random key pop-ups).
Hardware Isolation:
Plug in an external USB keyboard. If the USB keyboard works perfectly while built-in keys do not, the internal keyboard ribbon cable is loose, or the keyboard membrane is physically damaged (often from dust or liquid spills).
